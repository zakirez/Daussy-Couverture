DAUSSY COUVERTURE — REFONTE V2
Ouvrir index.html dans un navigateur connecté à Internet.
9 pages HTML, CSS et JavaScript reconstruits d'après le véritable code du modèle Plombier Paris (hero pleine largeur, header transparent, zoom lent, vague de lettres, cartes animées, navigation responsive).

Médias : logo graphique et photo de chantier identifiés sur le site d'origine, chargés par leurs URL exactes. Les fichiers binaires n'ont pas pu être téléchargés dans l'environnement de création. La photo de couverture est utilisée comme visuel générique provisoire sur plusieurs pages. Les polices sont chargées depuis le site modèle, avec Arial en secours. La palette est déduite visuellement du logo (bleu foncé, bleu moyen, rouge), sans mesure des couleurs CSS originales.

Pour récupérer les fichiers localement : installer Python 3 si nécessaire, puis dans ce dossier lancer python recuperer-images.py (ou py recuperer-images.py sous Windows). Le script télécharge les médias accessibles des pages principales et des albums et crée un inventaire JSON. Vérifier les images et affecter les fichiers appropriés aux noms couverture.jpg, zinguerie.jpg, bardage.jpg, approche.jpg et zone.jpg. Les images locales sont utilisées automatiquement si elles existent. Les photos additionnelles doivent être sélectionnées et intégrées manuellement à la galerie.

Les formulaires de témoignage et de contact renvoient au site original : aucun serveur de traitement n'est installé. Pas de faux avis, pas de mentions légales recréées. Pas de mise en ligne. Les pages de référencement local sont reliées au site original, non recréées intégralement.
